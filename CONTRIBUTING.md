# Contributing

Thank you for considering contributing to this project! We welcome all kinds of contributions, especially from beginners and Hacktoberfest participants.

## How to Contribute

1. **Fork** the repository.
2. **Clone** your fork to your local machine.
3. **Create a new branch** for your changes.
4. Make your changes (HTML/CSS only).
5. **Commit** your changes with a clear message.
6. **Push** them to your fork.
7. **Open a Pull Request** on this repo.

## Code Style

- Use consistent indentation in HTML and CSS.
- Comment your code when necessary.

## Reporting Bugs

- Open an issue with a clear description.
- Include screenshots or steps to reproduce the bug.

## Suggesting Features

- If you have an idea or improvement, open an issue and describe your suggestion.

## Etiquette

- Be respectful in issues and pull requests.

Happy contributing!
